# 浏览器扩展（MV3）/ Browser extension

`extension/` 是一个 Chrome/Edge Manifest V3 扩展：**嗅探网页资源、接管浏览器下载、
悬浮按钮一键发送**到 downloadmgr 桌面应用（仅 127.0.0.1 回环，无遥测）。

## 安装 / 更新

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）；开发者模式
2. 首次：「加载已解压的扩展程序」→ 选 `extension` 目录
3. **代码更新后**：在该扩展卡片上点「刷新 ⟳」；如果弹出新权限提示，确认即可
4. 扩展 ID 由文件夹路径决定：**移动文件夹会换 ID，需要重新配对**

## 配对（默认全自动）

**扩展装好后无需任何操作**：只要桌面应用在运行，扩展就会自动完成配对
（安装时、浏览器启动时、打开弹窗时、发送失败时都会自动尝试）。

安全边界与开关：

- 自动配对**只对浏览器扩展生效**——网页永远无法配对（浏览器保证网页无法伪装扩展 Origin）
- 应用「设置 → 浏览器捕获 → 允许扩展自动配对」可整体关闭；关闭后走配对码流程
- 「已配对扩展」里**撤销**某个扩展后，它**无法再自动配对**（需配对码手动恢复）——
  保证"撤销"是算数的
- 自动配对上限定 10 个扩展

手动配对（备用）：桌面应用 → 设置 → 浏览器捕获 → 「生成配对码」（6 位，5 分钟，单次）
→ 扩展选项页输入。配对同时下发两个令牌：捕获令牌（发送资源）与协议令牌
（应用没开时冷启动它）。

## 功能

### 1. 资源嗅探（含角标计数）

浏览任何网页时，扩展在后台观察响应头，识别"值得下载"的东西：
视频/音频文件、压缩包、安装包、文档、大模型权重、attachment 响应；
并自动过滤垃圾（HLS/DASH 分片 `.ts/.m4s`、`videoplayback` 分块、
`range=` 片段、API/JSON 噪音）。识别到的数量显示在工具栏图标角标上。

> 说明：`.m3u8/.mpd` 流清单**暂不采集**——桌面引擎目前不支持 HLS/DASH，
> 采了也只是下到一个几 KB 的清单文件。等流媒体支持上线后开放。

### 2. 下载接管（IDM 行为）

浏览器里点击任何下载链接 / 视频保存 → 浏览器下载被取消 → 任务直接进应用。
规则可在选项页配置：接管总开关、按类别（视频/音频/压缩包/程序/文档/大模型）、
追加自定义扩展名、体积下限、排除列表。

**安全门**：仅在**应用已配对且可达**时才接管；应用没开或没配对时，
浏览器下载照常进行（不会出现"下载被取消却没送到"的丢文件情况）。

### 3. 悬浮下载按钮

鼠标移到网页视频上时，右上角浮出「⬇ 下载该视频」按钮。
点击后优先发送**网络嗅探到的真实媒体直链**（大小最大者），
其次视频元素的直链 src。

> 说明：只在能解析出**直链**时出现（blob/MSE 播放且没嗅探到直链就不显示）——
> 桌面引擎目前不解析 YouTube/B站这类平台页面，发送页面 URL 只会下到 HTML。

### 4. 弹窗

点扩展图标：本页嗅探到的资源清单（勾选 → 发送到应用 / 全选 / 清空），
顶部显示应用在线/配对状态，底部有接管开关和选项入口。

### 5. 右键菜单

- **用 downloadmgr 下载此链接**（链接/视频/音频/图片）
- **把本页资源全部发给 downloadmgr**（页面）
- **接管下载** 勾选开关（图标上右键）

### 6. 应用未运行时

发送失败的任务进入持久队列，扩展同时尝试用 `downloadmgr://open` 冷启动应用；
之后每 30 秒重试投递（退避上限 2 分钟），应用启动后自动送达。

## 权限与理由

| 权限 | 理由 |
|------|------|
| `webRequest` + `<all_urls>`（host） | 观察响应头做资源嗅探；这是"不用下载就能发现资源"的前提 |
| `downloads` | 接管：监听 onDeterminingFilename 并取消浏览器下载 |
| `content_scripts`（`<all_urls>`） | 悬浮下载按钮与视频命中检测 |
| `tabs` / `webNavigation` | 按标签页维护资源清单、页面切换时清理 |
| `storage` / `alarms` | 设置、队列、定时重试 |
| `notifications` | 未配对/应用未运行提示 |
| `host_permissions: http://127.0.0.1/*` | 直接访问本地应用捕获 API（无需任何 CORS） |

**安全姿态**（与同类产品不同之处）：本地 API 有配对令牌 + Origin 钉死；
令牌只存在于 SW 与选项页，永不进入网页上下文；没有内容脚本发起的网络请求。

## 故障排查

| 现象 | 处理 |
|------|------|
| 角标一直 0 | 该页确实没有可直链资源；或在排除列表里；或播放的是 HLS/DASH 流 |
| 点击下载没被接管 | 应用未运行/未配对（这是安全门）；或该扩展名不在接管类别里 |
| 弹窗显示"未配对" | 应用里生成新配对码，扩展选项页重新配对 |
| 悬浮按钮不出现 | 视频是 blob/MSE 且本页没嗅探到直链媒体 |
| 更新扩展后冷启动失效 | 重新配对一次（新版本才下发协议令牌） |
| 应用换了端口 | 扩展自动扫描 8787–8807；或选项页手动填端口 |
